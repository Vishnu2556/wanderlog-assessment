# Wanderlog

Wanderlog is a dynamic web application designed to help users seamlessly log, track, and manage their travel experiences. Built as a comprehensive system development project, the application offers an intuitive interface to document trips, manage itineraries, and keep memories organized.

---

## 🚀 Features

* **User Authentication:** Secure signup and login functionality to keep personal travel logs private.
* **Interactive Travel Logs:** Create, edit, and delete detailed logs of your trips, including destinations, dates, and personal notes.
* **Itinerary Management:** Plan and organize daily activities, accommodations, and transit details.
* **Responsive Design:** Optimized for a seamless experience across desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

### Frontend
* **React.js (Vite):** Fast, component-based user interface development.
* **CSS3 / Vanilla CSS:** Custom styled layouts and responsive designs.

### Deployment & Configuration
* **Vercel:** Optimized hosting and continuous deployment for the frontend application.
